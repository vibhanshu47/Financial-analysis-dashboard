# Financial Sector Analysis

A financial analysis dashboard built with Python and Flask. It uses stock market data to analyze price trends and moving-average crossovers.

## Features

- Get stock market data using `yfinance`
- Analyze stock price trends
- Calculate 20-day and 50-day moving averages
- Display stock charts
- Identify potential BUY and SELL signals

## Tech Stack

- Python
- Flask
- Pandas
- NumPy
- Matplotlib
- yfinance
- HTML
- CSS
- Jinja2

How to Run Locally
Clone the repository: git clone https://github.com/[YourUsername]/[RepoName].git
Install dependencies: pip install flask yfinance pandas matplotlib
Run the server: python app.py
Open http://127.0.0.1:5000 in your browser.
